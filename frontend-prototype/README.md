QA Panel - Frontend Prototype

Este proyecto es un prototipo frontend minimal para revisar las pantallas solicitadas.

Requisitos:
- Node.js 18+ y npm

Instalación:

PowerShell (Windows):

```powershell
cd "c:\Users\Aday Mathers\Documents\VS Code\QA Panel\frontend-prototype"
npm install
npm run dev
```

Abrir en el navegador la URL que muestre Vite (normalmente http://localhost:5173).

Notas:
- Los datos son mock y están en `src/mocks/mockData.js`.
- Esto es un prototipo para validar flujo y UX. Puedo añadir más detalle o conectar a un backend cuando lo apruebes.
