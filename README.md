# NextQA
Plataforma multiusuario para control de calidad industrial. Gestión de clientes, proyectos, productos, checklists, reportes PDF y métricas KPI en tiempo real.


我正在向您介紹“NextQA”，這是一款完全由我獨立開發的工業品質控制軟體。

🔍 主要功能：

多用戶：專為大中型企業的 QA 和管理團隊設計。
全面管理客戶、專案、產品和流程。
建立和編輯檢查清單，並設定視覺和尺寸標準。
互動式繪圖顯示（畫布）、自動縮放和按檢查點導航。
自動產生 PDF 報告並儲存在資料庫中，用於指標和歷史記錄檢視。
自動發送關鍵缺陷電子郵件通知，並提供可編輯的收件者清單。
“矩陣”式儀表板，用於查看每個檢查點的狀態。
管理儀表板包含 KPI 指標、缺陷圖表和統計流程控制。
整合全域聊天功能，用於內部溝通，避免在工作中使用 WhatsApp。
現代、緊湊、響應迅速的介面，已針對桌面和平板電腦進行最佳化。
💡 我親自開發了整個項目，從後端（Node.js + Prisma）到前端（React + Vite），優先考慮可用性和麵向非技術用戶的全面功能。
